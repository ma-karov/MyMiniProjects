# Цель
## Создать парсер, который собирает данные о статьях из 
последнего выпуска журнала на сайте. Парсер реализован 
на TypeScript единым файлом.
=
Описание задачи:  
1. Переход к списку выпусков:  
- Парсер должен начать с указанной страницы журнала  
    https://newjournal.ssmu.kz/publication/releases/ (переход в раздел с выпусками).  
- Выбрать выпуски журнала за текущий год.  
2. Извлечение данных со страницы содержания выпуска:  
- Собрать ссылки на статьи  
- Если выпуск не поделен на статьи – считать весь выпуск единой сущностью.  

3. Переход на страницу каждой статьи:
- После извлечения Title и Authors со страницы содержания, перейти на 
  индивидуальную страницу каждой статьи.  
- Собирать:  
    • Title  
    • Authors  
    • Abstract (аннотация к статье)  
    • Скачать и распарсить PDF для извлечения полного текста (pdf_text),  
      если pdf-не содержит текста или полностью состоит из «скана/изображения»,  
      текст заменить на «пустая - pdf»  
    • URL – ссылка страницы сбора данных  
    • URL pdf – Ссылка на скачивание pdf (оригинальная)  
 
4. Обработка PDF:
   - Парсер должен скачать PDF-файл, который прикреплен к статье, и извлечь текст из него. Извлечение должно быть корректным, с соблюдением структуры текста.
