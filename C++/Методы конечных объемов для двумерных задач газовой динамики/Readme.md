# Задачи вычислительной газовой динамики имеют большую важность и  
актуальность во многих областях современной науки и техники.  
Наиболее эффективными методами решения этих задач остаются  
численные методы. В данной ветке будет рассмотрен метод конечных  
объемов применительно к двумерным задачам газовой динамики. 
=
### Рассмотрим задачу о течении газа в канале со ступенькой.  
Ступенька высотой 0.2 расположена на расстоянии 0.6 от левой  
границы. Высота расчетной области равна 1, длина равна 3. 
Положим следующие параметры набегающего потока:
• идеальный газ с показателем адиабаты γ = 1.4;
• число Маха M = 3;
• плотность ρ = 1;
• давление p = 1/γ;
• компоненты скорости v = (u, v) = (3, 0).
